# CRM-система на Django 5.2

## 📌 О проекте
Backend-система CRM, разработанная на Django как модульная система для управления клиентами, задачами и внутренними процессами компании.

Проект основан на реальной коммерческой CRM-системе (работавшей в продакшене). Данный репозиторий содержит **обезличенную версию без бизнес-данных и внешних зависимостей**, предназначенную для демонстрации архитектуры и ключевых технических решений.

Основной фокус системы — обработка бизнес-процессов, интеграции с почтой по imap и автоматизация коммуникаций.

## 🧩 Основной функционал
**Управление клиентами и компаниями**
- ведение карточек компаний
- связь с задачами и уведомлениями

**Система задач**
- постановка и распределение задач между менеджерами
- контроль статусов выполнения
- привязка задач к клиентам

**Система напоминаний**
- создание напоминаний
- привязка к компаниям и заявкам

**Почтовая интеграция**
- получение писем через IMAP
- отображение входящей почты в интерфейсе
- базовая обработка и синхронизация писем
---

## 🧱 Архитектура проекта
Проект построен как модульная Django-система с разделением по бизнес-доменам:
**account** - модуль авторизации
**comments** - управление переговорами с клиентами
**companies** - управление клиентами и организациями
**tasks** — модуль управления задачами (создание, генерация отчетов)
**reminders** — система напоминаний
**requests** — система заявок (создание, просмотр, удаление)
**mail** — интеграция с IMAP (отображение писем)
**core** — базовая инфраструктура и UI-теги

**Архитектурные принципы:**
- разделение бизнес-доменов по Django apps
- изоляция интеграций (почта, внешние сервисы)
- перенос бизнес-логики из views в отдельные слои
- расширяемость под новые модули без изменения ядра системы

## ⚙️ Разворачивание проекта
### 1. Клонируйте репозиторий
```bash
git clone https://github.com/username/crm-django.git
cd crm-django
```

### 2. Создайте виртуальное окружение и установите зависимости
```bash
python -m venv venv
source venv/bin/activate   # Linux/MacOS
venv\Scripts\activate      # Windows

pip install -r requirements.txt
```

### 3. Настройте переменные окружения
Создайте файл .env в корне проекта и заполните его:
```bash
SECRET_KEY=ваш_секретный_ключ
DEBUG=True
ALLOWED_HOSTS=127.0.0.1,localhost

DB_NAME=crm
DB_USER=postgres
DB_PASSWORD=postgres
DB_HOST=localhost
DB_PORT=5432

EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_HOST_USER=your_email@gmail.com
EMAIL_HOST_PASSWORD=your_password
EMAIL_USE_TLS=True

IMAP_HOST=imap.gmail.com
IMAP_PORT=993
IMAP_USER=your_email@gmail.com
IMAP_PASSWORD=your_password
```

### 4. Подготовьте базу данных
Если используется PostgreSQL:
```bash
createdb crm -U postgres
```

### 5. Примените миграции
```bash
python manage.py migrate
```

### 6. Создайте суперпользователя
```bash
python manage.py createsuperuser
```

### 7. Соберите статические файлы
```bash
python manage.py collectstatic
```

### 8. Запустите сервер
```bash
python manage.py runserver
```
